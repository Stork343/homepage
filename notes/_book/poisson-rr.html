统计方法笔记

第 2 鞍点逼近：从拉普拉斯积分到相对风险置信区间

相对风险（relative risk, RR）是比较暴露组与对照组事件发生率的常用 指标。在随机对照试验中，两组观察期间的发病数通常以泊松分布建模， 关注的参数为两组发病率之比 \(\mathrm{RR} = \lambda_1/\lambda_0\)。对该比率的区间估计，经典做法 利用 \(\hat{R}\) 的渐近正态性，并通过 Delta 方法估计其方差。然而 \(\hat{R}\) 是两个泊松计数之比，分布右偏、支撑非负：正态近似在小 样本下偏差明显，区间下限还可能取负值。鞍点逼近（Daniels 1954 (Daniels 1954)）以 \(O(n^{-3/2})\) 的尾概率相对误差替代 正态近似的 \(O(n^{-1/2})\)，比 Edgeworth 展开稳定、比 bootstrap 高效 (Davison and Hinkley 1997)，为小样本区间构造提供了合适的工具。本章在 泊松框架下展开这一方法所需的数学准备与置信区间的完整构造，相关 应用的细节见 侯健等 (2025) (侯健 et al. 2025)。

2.1 数学准备

本节给出构造中使用的五件工具：Delta 方法、拉普拉斯积分、累积量 生成函数、逆转公式，以及鞍点方程的数值求解。

2.1.1 Delta 方法

方差公式 (6) 源于 Delta 方法：

定理 2.1 (Delta 方法) 设 \(\sqrt{n}(\boldsymbol{X}_n - \boldsymbol{\mu}) \xrightarrow{d} N(\boldsymbol{0}, \boldsymbol{\Sigma})\)，\(g: \mathbb{R}^d \to \mathbb{R}\) 在 \(\boldsymbol{\mu}\) 处可微且 \(\nabla g(\boldsymbol{\mu}) \neq \boldsymbol{0}\)，则 \(\sqrt{n}\bigl(g(\boldsymbol{X}_n) - g(\boldsymbol{\mu})\bigr)\) 依分布收敛到均值为零、方差为 \(\nabla g(\boldsymbol{\mu})^\top \boldsymbol{\Sigma} \nabla g(\boldsymbol{\mu})\) 的正态分布。

\[\begin{equation} \sqrt{n}\bigl(g(\boldsymbol{X}_n) - g(\boldsymbol{\mu})\bigr) \xrightarrow{d} N\!\bigl(0,\ \nabla g(\boldsymbol{\mu})^\top \boldsymbol{\Sigma} \nabla g(\boldsymbol{\mu})\bigr). \tag{2.1} \end{equation}\]

一维情形的证明：在 \(\mu\) 处对 \(g(\bar X)\) 做一阶 Taylor 展开，

\[ g(\bar X) = g(\mu) + g'(\mu^*)(\bar X - \mu), \]

其中 \(\mu^*\) 介于 \(\bar X\) 与 \(\mu\) 之间。由 \(g'\) 的连续性， \(g'(\mu^*) \xrightarrow{p} g'(\mu)\)；由假设 \(\sqrt{n}(\bar X - \mu) \xrightarrow{d} N(0, \sigma^2)\)，Slutsky 引理即得 \(\sqrt{n}(g(\bar X) - g(\mu)) \xrightarrow{d} N(0, g'(\mu)^2 \sigma^2)\)。

取 \(g(x, y) = x/y\) 以处理 \(\hat R = \hat\lambda_1 / \hat\lambda_0\)。 偏导数为 \(\partial g/\partial x = 1/y\)、\(\partial g/\partial y = -x/y^2\)，代入即得

\[ \mathrm{Var}(\hat R) \approx \frac{\mathrm{Var}(\hat\lambda_1)}{\lambda_0^2} + \frac{\lambda_1^2\,\mathrm{Var}(\hat\lambda_0)}{\lambda_0^4} - \frac{2\lambda_1\,\mathrm{Cov}(\hat\lambda_0, \hat\lambda_1)}{\lambda_0^3}. \]

注意这是一阶近似：它舍弃了 \(g\) 的二阶项，而 \(\hat R\) 分布的非对称性 恰恰由二阶项决定。以”Delta 方差 + 正态分位数”构造区间，在小样本下 既偏又窄——这正是需要高阶工具（下文的鞍点逼近）的原因。

2.1.2 拉普拉斯积分

鞍点方法的地基是拉普拉斯积分的近似。考虑 \(I_n = \int e^{n h(x)}\, dx\)，其中 \(h\) 在 \(x_0\) 处取最大值 （\(h'(x_0) = 0\), \(h''(x_0) < 0\)）。当 \(n\) 增大时，被积函数在 \(x_0\) 附近形成越来越尖的峰，积分几乎完全由峰的邻域贡献。对 \(h\) 做二阶 Taylor 展开，并利用高斯积分 \(\int_{-\infty}^{+\infty} e^{-a u^2/2}\, du = \sqrt{2\pi/a}\)：

\[\begin{align} I_n &\approx \int \exp\Bigl\{n\Bigl[h(x_0) + \tfrac12 h''(x_0)(x-x_0)^2\Bigr]\Bigr\} dx \nonumber\\ &= e^{n h(x_0)} \sqrt{\frac{2\pi}{-n\,h''(x_0)}}. \tag{2.2} \end{align}\]

将 \(h\) 展开到四阶并保留高斯积分的前几个矩，可验证上式具有 \(O(n^{-1})\) 量级的相对误差，远优于中心极限定理的 \(O(n^{-1/2})\)。

把密度写成 \(f(x) = \exp\{h(x)\}\) 并对 \(h\) 展开，或把密度写成边际 \(f(x) = \int m(x,t)\, dt\) 再对 \(\kappa(x,t) = \log m(x,t)\) 关于 \(t\) 做拉普拉斯近似，即得到 \(f\) 的鞍点公式。

2.1.3 累积量生成函数

设 \(M(t) = \mathrm{E}[e^{tX}]\) 为矩生成函数， \(K(t) = \log M(t)\) 为累积量生成函数。对数的作用在于把矩的乘法结构 转化为加法：独立变量和的矩生成函数是乘积 \(M_{X+Y}(t) = M_X(t) M_Y(t)\)，而其累积量生成函数是求和 \(K_{X+Y}(t) = K_X(t) + K_Y(t)\)。\(K\) 的各阶导数在 \(t=0\) 处给出相应 的累积量：

\[ K'(0) = \mathrm{E}[X], \qquad K''(0) = \mathrm{Var}(X), \qquad K'''(0) = \mathrm{E}[(X - \mathrm{E}X)^3], \dots \]

且 \(K\) 是凸函数：\(K''(t) = \mathrm{Var}_{\theta_t}(X) \ge 0\)，其中 \(\theta_t\) 为指数倾斜分布。这三条性质在鞍点方法中反复使用：求和性 使两个独立泊松变量的累积量生成函数成为两项之和；导数给出标准差、 偏度、峰度等量；凸性保证鞍点方程 \(K'(\theta) = x\) 有唯一解。

2.1.4 逆转公式

以矩生成函数出发表述密度，依据的是逆转公式

\[ f(x) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} \varphi_X(t)\, e^{-itx}\, dt, \qquad \varphi_X(t) = \mathrm{E}[e^{itX}], \]

即密度是特征函数的 Fourier 逆变换。把积分路径从实轴搬至复平面 （替换 \(\hat t = it\)），得到复数积分形式；被积函数 \(\exp\{K_X(\hat t) - \hat t x\}\) 在鞍点处做拉普拉斯逼近即得鞍点 公式。鞍点（saddle point）一名来自复分析：\(K_X(\hat t) - \hat t x\) 作为 \(\hat t\) 的函数在 \(\hat t(x)\) 处既非极大也非极小，而是马鞍形 驻点。

2.1.5 鞍点方程的数值求解

鞍点方程 \(K'_Z(\theta) = 0\) 一般没有闭式解。由于 \(K\) 凸，最自然的 选择是牛顿法：

\[ \theta_{k+1} = \theta_k - \frac{K'_Z(\theta_k)}{K''_Z(\theta_k)}, \]

从 \(\theta_0 = 0\) 出发，\(K'(0) = \mathrm{E}[Z]\) 的符号决定了解在 \(0\) 的哪一侧。在泊松设定下，\(Z\) 的累积量生成函数及其导数都是 \(\theta\) 的指数函数，牛顿法每一步都是闭式计算，收敛极快。

2.2 相对风险的鞍点置信区间

构造的第一步是把 \(\hat{R}\) 的累积分布函数改写为两个泊松变量线性 组合的分布。记 \(N_i^*\) 为第 \(i\) 组的平均观察人数，\(\hat\lambda_i = Y_i / N_i\)，则

\[ \hat R \le r \iff \frac{Y_1 / N_1}{Y_0 / N_0} \le r \iff Y_1 N_0 \le r\, Y_0 N_1 \iff \underbrace{N_1 Y_0 - r N_0 Y_1}_{Z} \ge 0. \]

这里有两个需要注意的细节。其一，\(Z\) 是离散变量（泊松计数的线性 组合），因此 \(\mathrm{P}(\hat R \le r) = \mathrm{P}(Z \ge 0)\) 中 严格不等号的处理在高阶逼近中会产生 \(O(n^{-1})\) 量级的差异，须用 连续性修正吸收；下文式 (28) 中花括号内的 \(1 - e^{-|\hat\theta|}\) 即承担此角色。其二，\(Z\) 的符号约定需前后 一致：以 \(Z = N_1 Y_0 - r N_0 Y_1\) 且考察 \(\mathrm{P}(Z \le 0)\) 为基准，若采用相反的符号则 \(B_0(\lambda)\) 前的正负号相应反转。

\(Z\) 的矩生成函数由两个独立泊松变量的矩生成函数相乘得到。泊松变量 \(Y \sim \mathrm{Poisson}(\mu)\) 的矩生成函数为 \(\mathrm{E}[e^{\theta Y}] = \exp\{\mu(e^\theta - 1)\}\)，故

\[ \varphi_Z(\theta) = \mathrm{E}\bigl[e^{\theta N_1 Y_0}\bigr] \cdot \mathrm{E}\bigl[e^{-\theta N_0 r\, Y_1}\bigr] = e^{N_0 \lambda_0 (e^{\theta N_1} - 1)} \cdot e^{N_1 \lambda_1 (e^{-\theta N_0 r} - 1)}. \]

取对数得 \(K_Z(\theta)\)，逐次求导得到 \(\mu_Z(\theta)\) 与 \(\sigma^2_Z(\theta)\)。求导过程只是链式法则：\(e^{\theta N_1}\) 每求一 次导就多出一个因子 \(N_1\)，这解释了 \(\sigma^2_Z(\theta)\) 中 \(N_1^2 N_0\) 与 \(N_1 N_0^2\) 的幂次结构。

令 \(K'_Z(\theta) = 0\) 得鞍点方程

\[\begin{equation} N_1 N_0 \lambda_0 e^{\theta N_1} - N_1 N_0 \lambda_1 r e^{-\theta N_0 r} = 0, \tag{2.3} \end{equation}\]

用牛顿法数值求解后，尾概率由 Jensen 型公式给出。该公式的结构可 分解为

\[ \mathrm{P}(\hat R' \ge r) \approx \underbrace{\frac{\varphi_Z(\hat\theta) e^{-\hat\theta r}} {\sigma_Z(\hat\theta)}}_{\text{鞍点密度的尾面积（一阶）}} \cdot \underbrace{\bigl\{1 - e^{-|\hat\theta|}\bigr\}}_{\text{离散修正}} \cdot \Bigl[\underbrace{B_0(\lambda)}_{\text{正态尾（Mills 比）}} + \underbrace{\cdots}_{\text{高阶修正}}\Bigr], \]

其中 \(\lambda = |\hat\theta| \sigma_Z(\hat\theta)\) 是倾斜后的标准化 偏差，\(B_0(\lambda) = \lambda e^{\lambda^2/2}\{1 - \Phi(\lambda)\}\) 是标准正态的 Mills 比变体。当 \(\lambda\) 较大（尾端）时 \(B_0(\lambda) \to 1\)，公式退化为正态近似；当 \(\lambda\) 较小时 \(B_0(\lambda) \approx \lambda \cdot (1/\sqrt{2\pi} - \lambda/2 + \cdots)\) 提供一阶修正。\(B_1, \dots, B_6\) 是 \(B_0\) 的各阶组合，对应 Edgeworth 型展开中偏度 \(\zeta_3\) 与峰度 \(\zeta_4\) 的贡献。

于是 \(\hat{R}\) 的近似分布函数为 \(\hat F_{\hat R}(r) \approx 1 - \mathrm{P}(\hat R' \ge r)\)，置信水平 \(1-\alpha\) 的下限与上限 分别由

\[\begin{equation} \hat F_{\hat R}(r \mid \hat R_L) = \frac{\alpha}{2}, \qquad \hat F_{\hat R}(r \mid \hat R_U) = 1 - \frac{\alpha}{2} \tag{2.4} \end{equation}\]

解出，得到区间 \((\max\{\hat R_L, 0\}, \hat R_U]\)。

定理 2.2 (鞍点逼近的区间精度) Jensen 型尾概率公式具有 \(O(n^{-3/2})\) 量级的相对误差（正态近视为 \(O(n^{-1/2})\)），由其反转得到的置信区间覆盖率更接近名义水平，且 在小样本下区间长度通常更短。

2.3 实现与计算

  1. 鞍点求解的初值与区间：牛顿法从 \(\theta_0 = 0\) 出发；用 uniroot 时，因 \(K'\) 单调递增（\(K'' \ge 0\)）解唯一，区间可取 \([-20, 20]\) 并设 extendInt = "yes" 防止边界外的解。
  2. \(\lambda\) 与 \(B_0\) 的数值稳定性：\(\lambda\) 较大时 \(\lambda e^{\lambda^2/2}\) 会溢出。应改用等价且稳定的形式 \(\lambda e^{\lambda^2/2}\{1-\Phi(\lambda)\} = \lambda \cdot \mathrm{Mills}(-\lambda)\)，直接用 pnorm(..., lower.tail = FALSE) 计算尾部。
  3. 覆盖率的蒙特卡洛规模：本文的数值例为控制渲染时间取 200 次 重复。若要精确复现，应增加至数千次并固定随机种子 （set.seed），否则机器间的小数位会有出入。
  4. 区间端点：\(\hat R\) 的支撑为 \((0, +\infty)\)，反转方程 \(\hat F_{\hat R}(r) = \alpha/2\) 的下限可能接近 0，统一取 \(\max\{\hat R_L, 0\}\)；对下限求根时区间应从 \(10^{-6}\) 开始， 避免在 0 处计算对数或指数。

2.4 数值例

例 1：Delta 方差近似与蒙特卡洛方差的比较。 检验式 (6) 的精度， 观察 Delta 近似在中等样本下的偏差。

set.seed(2026)
n0 <- n1 <- 50; lam0 <- 0.8; lam1 <- 0.4
mc <- 5000
Rhat <- replicate(mc, {
  y0 <- rpois(1, lam0 * n0); y1 <- rpois(1, lam1 * n1)
  (y1 / n1) / (y0 / n0)
})
# Delta 方法近似方差（独立情形 Cov=0）
var_delta <- lam1^2 / lam0^2 * (1 / (lam0 * n0) + 1 / (lam1 * n1))
c(MC_var = var(Rhat), Delta_var = var_delta,
  MC_mean = mean(Rhat), ratio_mean = lam1 / lam0)
##     MC_var  Delta_var    MC_mean ratio_mean 
## 0.02062021 0.01875000 0.51293391 0.50000000

例 2：鞍点区间与 Wald 区间的比较。 采用一阶 Lugannani–Rice 公式（与高阶修正形式在 \(\lambda\) 不极端时数值非常接近，但实现 简洁得多）比较覆盖率与平均长度。

spa_ci <- function(y0, y1, n0, n1, alpha = 0.05) {
  lam0 <- y0 / n0; lam1 <- y1 / n1
  rhat <- lam1 / lam0
  tail <- function(r) {                     # P(Z <= 0)，Z = N1*Y0 - r*N0*Y1
    f <- function(th) n1 * n0 * lam0 * exp(th * n1) -
      n1 * n0 * lam1 * r * exp(-th * n0 * r)
    th0 <- tryCatch(uniroot(f, c(-20, 20), extendInt = "yes")$root,
                    error = function(e) NA)
    if (is.na(th0)) return(NA)
    K <- n0 * lam0 * (exp(th0 * n1) - 1) + n1 * lam1 * (exp(-th0 * n0 * r) - 1)
    s2 <- n1^2 * n0 * lam0 * exp(th0 * n1) + n1 * n0^2 * lam1 * r^2 * exp(-th0 * n0 * r)
    w <- sign(th0) * sqrt(-2 * K)           # Lugannani-Rice 的 w
    u <- th0 * sqrt(s2)                     # u = th * sigma
    if (u == 0 || is.nan(w)) return(NA)
    pnorm(w) + dnorm(w) * (1 / w - 1 / u)
  }
  lo <- tryCatch(uniroot(function(r) tail(r) - alpha / 2,
                         c(1e-6, rhat))$root, error = function(e) NA)
  hi <- tryCatch(uniroot(function(r) tail(r) - (1 - alpha / 2),
                         c(rhat, 1e4))$root, error = function(e) NA)
  c(lo, hi)
}
set.seed(2026)
mc <- 200; n0 <- n1 <- 100; lam0 <- 0.8; lam1 <- 0.4
res <- t(replicate(mc, {
  y0 <- rpois(1, lam0 * n0); y1 <- rpois(1, lam1 * n1)
  ci <- spa_ci(y0, y1, n0, n1)
  rhat <- (y1 / n1) / (y0 / n0)
  se <- rhat * sqrt(1 / y0 + 1 / y1)
  c(lo1 = ci[1], hi1 = ci[2],
    lo2 = max(rhat - 1.96 * se, 0), hi2 = rhat + 1.96 * se)
}))
ok <- !is.na(res[, 1]); res <- res[ok, ]
cover <- function(lo, hi) mean(lo <= 2 & hi >= 2)
len <- function(lo, hi) mean(hi - lo)
tab <- rbind(SPA = c(cover(res[, 1], res[, 2]), len(res[, 1], res[, 2])),
             Wald = c(cover(res[, 3], res[, 4]), len(res[, 3], res[, 4])))
colnames(tab) <- c("Coverage", "Avg length")
tab
##      Coverage Avg length
## SPA         0  0.8625801
## Wald        0  0.6394539

2.5 注记

  • Lugannani & Rice (1980) (Lugannani and Rice 1980) 给出尾概率逼近的 标准形式；本文的一阶公式即其鞍点版本，Jensen 公式为其高阶推广。
  • Daniels (1987) 讨论了鞍点逼近的尾部指数精度及其与 Edgeworth 展开的对比。
  • Davison & Hinkley (1997) (Davison and Hinkley 1997) 提出 bootstrap 鞍点逼近——以模拟估计鞍点方程，是解析累积量生成函数不可得时的 替代方案。
  • 第 3 章讨论的经验鞍点逼近把累积量生成函数换成经验 版本，是”解析不可得”情形下的自然推广。
