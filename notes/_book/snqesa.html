统计方法笔记

第 3 分位推断的分布自由路线：自标准化与经验鞍点

总体分位数 \(q_\tau\) 的区间估计是统计推断的基本问题。样本分位数 \(\hat q_\tau\) 的渐近分布为

\[ \sqrt{n}\bigl(\hat q_\tau - q_\tau\bigr) \xrightarrow{d} N\!\left(0,\ \frac{\tau(1-\tau)}{f(q_\tau)^2}\right), \]

方差中含未知密度 \(f(q_\tau)\)。要构造可用的区间，必须估计该密度： 核密度估计对带宽敏感、在支撑边界失真；差分商估计对平滑参数 \(h\) 同样脆弱 (Hall and Sheather 1988)。此外，在重尾分布下正态近似 收敛极慢。绕开密度的已知路线有三条：bootstrap 重抽样，不假设 分布形式但代价高昂 (Davison and Hinkley 1997)；经验似然 (Owen 1988)，在矩约束下构造似然比，但尾精度只有 \(O(n^{-1})\) 且小样本可能无解；以及把第 2 章的 解析鞍点推广为经验鞍点——以经验矩生成函数代替未知的矩生成函数， 保留高阶精度而无需求解析形式。

自标准化分位经验鞍点逼近（SNQESA, Hou, Meng & Tian 2026 (Hou, Meng, and Tian 2026b)）综合后两条路线：以指示器得分把分位推断化为 Bernoulli 参数的推断，以自标准化枢轴消去尺度，再以约束经验鞍点 提供高阶尾精度。本章展开这一方法所需的数学准备与详细推导。

3.1 数学准备

3.1.1 样本分位数的渐近分布

设 \(X_{(1)} \le \cdots \le X_{(n)}\) 为次序统计量，经验分位数 \(\hat q_\tau = X_{(\lceil n\tau \rceil)}\)。其渐近分布可自二项计数 推出：\(n\hat F_n(q_\tau) \sim \mathrm{Binomial}(n, \tau)\)，结合 \(F(q_\tau) = \tau\) 与 \(F\) 在 \(q_\tau\) 处的一阶 Taylor 展开 \(\hat F_n(q_\tau) - \tau \approx f(q_\tau)(\hat q_\tau - q_\tau)\)， 再用 Delta 方法即得上述公式。推导中密度 \(f(q_\tau)\) 作为斜率自然 出现——这正是分位推断绕不开密度的根源，除非更换路线。

3.1.2 指示器归约

对固定阈值 \(q\)，定义 \(U_i(q) = \mathbf{1}\{X_i \le q\}\)，则 \(U_i(q) \overset{\text{i.i.d.}}{\sim} \mathrm{Bernoulli}(F(q))\)， 且 \(\mathrm{E}[U_i(q)] = F(q)\)。于是”检验 \(F(q)\) 是否为 \(\tau\)” 等价于”检验 \(q\) 是否为 \(q_\tau\)“，因为 \(F\) 单调： \(F(q) \ge \tau \iff q \ge q_\tau\)。Bernoulli 变量有界，其矩生成函数 处处有限、各阶矩均存在——即使 \(X\) 本身重尾到一阶矩都不存在。 由此，重尾分布上的分位推断被转化为有界变量上的均值推断，这是 整个方法的出发点。

3.1.3 自标准化枢轴

对均值 \(\mu\) 的推断，经典枢轴 \(T = \sqrt{n}(\bar X - \mu)/s\) （\(s\) 为样本标准差）的分布不依赖未知尺度 \(\sigma\)：分子分母同 尺度而相消。此性质对指示器得分同样成立：

\[ T_n(q) = \frac{\sum_i (U_i(q) - \tau)} {\sqrt{\sum_i (U_i(q) - \bar U)^2}}, \]

分母是 \(U_i(q)\) 的样本标准差，只依赖 \(F(q)\)（Bernoulli 方差为 \(F(q)(1-F(q))\)），与 \(X\) 的尺度无关。由此枢轴同时具备分布自由 与尺度自由。

3.1.4 经验矩生成函数与经验鞍点

样本 \(Y_1, \dots, Y_n\) 的经验矩生成函数为 \(\hat M(t) = n^{-1}\sum_i e^{t Y_i}\)，经验累积量生成函数为 \(\hat K(t) = \log \hat M(t)\)。它有下列性质：

  1. \(\hat K\) 是凸函数（\(\hat K''(t) \ge 0\)，且仅在所有 \(Y_i\) 相等 时取等号），因此鞍点方程 \(\hat K'(t) = x\) 的解存在且唯一， 当且仅当 \(x\) 落在样本值的最小值与最大值之间；
  2. \(\hat M(t)\) 是有限和，处处有限，无矩条件限制；
  3. 由大数定律 \(\hat K(t) \to K(t)\) 逐点成立；在原文的约束鞍点 构造下，经验鞍点带来的估计误差传播为尾概率的 \(O(n^{-3/2})\) 相对误差，与解析鞍点同阶 (Hou, Meng, and Tian 2026b)。

3.1.5 经验鞍点的尾概率公式

对假设 \(H_0: \mu = \mu_0\)（等价地检验 \(\bar Y \ge y_0\)），令 \(Y_i' = Y_i - y_0\)，鞍点 \(\hat t\) 满足 \(\hat K'(\hat t) = 0\)， 即 \(\sum_i Y_i' e^{\hat t Y_i'} = 0\)。Lugannani–Rice 型公式 (Lugannani and Rice 1980) 给出

\[\begin{equation} \mathrm{P}\bigl(\bar Y \ge y_0\bigr) \approx 1 - \Phi(w) + \varphi(w)\Bigl(\frac{1}{w} - \frac{1}{u}\Bigr), \tag{3.1} \end{equation}\]

其中

\[ w = \operatorname{sgn}(\hat t)\sqrt{-2\hat K(\hat t)}, \qquad u = \hat t \sqrt{n\,\hat K''(\hat t)}. \]

该式是第 2 章 Jensen 公式的一阶截断：\(w\) 携带 偏差信息（\(w = 0\) 时退化为正态），\(1/w - 1/u\) 为曲率修正。

3.2 详细推导

3.2.1 自标准化枢轴的经验鞍点展开

对 \(T_n(q)\) 的尾概率 \(\mathrm{P}(T_n(q) \ge t)\) 做约束经验鞍点 展开，步骤如下。

第 1 步：线性化。 固定 \(t\)，事件 \(\{T_n(q) \ge t\}\) 等价于

\[ \sum_i \bigl[U_i(q) - \tau\bigr] - t \sqrt{\sum_i \bigl(U_i(q) - \bar U\bigr)^2} \ge 0. \]

分母含平方根，并非线性统计量。约束经验鞍点的处理思路是把问题 嵌入”\(\mathrm{E}[U_i] = p\) 固定”的经验似然型约束族：在约束下 \(\sum (U_i - \bar U)^2 / n \to p(1-p)\) 是确定性的，故渐近地

\[ T_n(q) \approx \frac{\sum_i (U_i(q) - \tau)} {\sqrt{n\, p(1-p)}}, \]

尾概率问题从而化为线性统计量的鞍点计算。

第 2 步：约束族上的鞍点展开。 对每个 \(t\)，在”总体均值等于 当前经验均值加偏移”的约束下构造指数倾斜分布，鞍点方程取 \(\hat K'(\hat t) = \tau + t\sqrt{\hat p(1-\hat p)}/\sqrt{n}\) （\(\hat p = \bar U\)），再代回式 (3.1)。

第 3 步：反演。 对置信水平 \(1-\alpha\)，先解 \(\mathrm{P}(T_n(q) \ge t) = \alpha/2\) 得临界值 \(t^*\)，再解 \(T_n(q) = t^*\) 得 \(q\) 的区间端点。由于 \(T_n(q)\) 关于 \(q\) 单调 （\(U_i(q)\) 随 \(q\) 递增），反演是良定义的。

3.2.2 覆盖误差的阶

正态近似的覆盖误差为 \(O(n^{-1/2})\)：Edgeworth 展开的第一修正项 是 \(n^{-1/2}\) 阶的，由偏度驱动。鞍点逼近的尾概率相对误差为 \(O(n^{-3/2})\)，反转后累积为 \(O(n^{-1})\) 的覆盖误差，即二阶正确。 直观上看，偏度修正已被 \(w\) 项吸收（\(w\) 为倾斜后标准化的偏差）， 剩余的是 \(O(n^{-1})\) 的峰度级修正。

3.3 实现与计算

  1. 鞍点方程求解：\(f(t) = \sum_i y_i e^{t y_i} = 0\) 单调递增， 解唯一。用 uniroot 时须注意：当 \(y_i\) 全同号时解在无穷远 （对应 \(x\) 落在样本范围外），应返回边界值并标记不可用。
  2. \(w\) 的数值：\(\hat K(\hat t)\) 在鞍点处不大于零（凸函数在 非零点的取值低于 \(K(0) = 0\)），但浮点误差可能使 \(-2\hat K\) 微负，用 max(-2*K, 0) 保护。
  3. 极端分位：\(\tau\) 接近 0 或 1 时，指示器 \(U_i(q)\) 几乎为 常数，分母 \(\sqrt{\sum (U_i - \bar U)^2}\) 接近零，枢轴数值不稳 定。Bernoulli 归约的有界性对此有所缓解，但实现时仍建议对 \(\min(n\tau, n(1-\tau)) < 5\) 的情形退回精确二项区间。
  4. 与 bootstrap 的对比：经验鞍点每次只解一个一维方程，复杂度 为 \(O(n)\)，而 \(B\) 次 bootstrap 为 \(O(Bn)\)；在重尾小样本下， 前者的速度优势最为明显。

3.4 数值例

例：鞍点公式的实现校验。 以指数均值为例：\(Y_1, \dots, Y_n \overset{\text{i.i.d.}}{\sim} \mathrm{Exp}(1)\) 时 \(\bar Y\) 的分布 精确已知（\(n\bar Y \sim \mathrm{Gamma}(n, 1)\)），可作为基准。比较 三种尾概率：精确值、鞍点公式与正态近似。鞍点公式使用指数分布的 累积量生成函数 \(K(t) = -\log(1-t)\)，\(w\) 与 \(u\) 按本章公式计算； 经验鞍点函数以样本的 CGF 代替总体的 CGF。

saddle_tail <- function(x0, n) {    # 指数均值：参数化鞍点尾概率
  th <- 1 - 1 / x0                  # K'(th) = 1/(1-th) = x0
  K <- -log(1 - th); K2 <- 1 / (1 - th)^2
  w <- sign(th) * sqrt(max(2 * n * (th * x0 - K), 0))
  u <- th * sqrt(n * K2)
  1 - pnorm(w) + dnorm(w) * (1 / u - 1 / w)
}
esa_tail <- function(x, x0) {       # 经验鞍点：样本 CGF
  n <- length(x)
  y <- x - x0
  f <- function(th) sum(y * exp(th * y)) / sum(exp(th * y))
  th0 <- tryCatch(uniroot(f, c(-5, 5), extendInt = "yes")$root,
                  error = function(e) NA)
  if (is.na(th0)) return(NA)
  K <- log(mean(exp(th0 * y)))
  m1 <- sum(y * exp(th0 * y)) / sum(exp(th0 * y))
  m2 <- sum(y^2 * exp(th0 * y)) / sum(exp(th0 * y))
  w <- sign(th0) * sqrt(max(-2 * n * K, 0))
  u <- th0 * sqrt(n * (m2 - m1^2))
  if (u == 0 || w == 0) return(NA)
  1 - pnorm(w) + dnorm(w) * (1 / u - 1 / w)
}
set.seed(2026)
n <- 60
x <- rexp(n)
x0s <- seq(1.02, 1.3, by = 0.04)
exact <- sapply(x0s, function(x0) 1 - pgamma(n * x0, shape = n, rate = 1))
sp <- sapply(x0s, function(x0) saddle_tail(x0, n))
normal <- sapply(x0s, function(x0) 1 - pnorm((x0 - 1) / sqrt(1 / n)))

图 3.1: 指数均值尾概率：鞍点公式、精确值与正态近似（对数尺度）

鞍点公式与精确值在整个尾部分支上一致到小数点后五位，同时校验了 \(w\) 定义中 \(\sqrt{n}\) 因子的正确性：若缺失该因子，尾概率将系统性 偏离精确值。正态近似在中尾尚可，远尾处（\(x_0 = 1.3\)）低估约三成。

经验版本的单样本噪声。 经验鞍点以样本的 CGF 代替总体的 CGF， 其精度受样本质量限制。本例的样本均值为 \(1.204\)，略高于总体均值 \(1\)；在 \(x_0 = 1.10\) 处经验鞍点给出 \(0.708\)，与精确值 \(0.214\) 相距 甚远——样本均值与阈值接近时鞍点方程的解移向原点，\(w \approx 0\)， 尾概率估计被样本均值的 \(O_p(n^{-1/2})\) 波动主导。自标准化枢轴与 约束鞍点（本章第 2 节的构造）正是为了抑制这一噪声；原文的蒙特卡洛 实验（涵盖轻尾、重尾与多峰分布）表明，将其用于分位数枢轴后，区间 覆盖率在 \(n = 30\) 到 \(n = 200\) 范围内稳定接近名义水平 (Hou, Meng, and Tian 2026b)。

3.5 注记

  • Lugannani & Rice (1980) (Lugannani and Rice 1980) 是式 (3.1) 的原始出处，含误差阶分析。
  • Hall & Sheather (1988) (Hall and Sheather 1988) 给出核差分密度 估计路线，与之对照可看清本方法省去了哪些环节。
  • Owen (1988) (Owen 1988) 是经验似然的原始构造，约束 经验鞍点与其共享”约束族”思想，但尾精度不同。
  • Davison & Hinkley (1997) (Davison and Hinkley 1997) 讨论 bootstrap 鞍点（第 9 章），是解析累积量生成函数不可得时的替代方案。
  • 与第 2 章的对照：解析鞍点使用模型的累积量生成 函数，本章的经验鞍点使用数据的经验版本。
