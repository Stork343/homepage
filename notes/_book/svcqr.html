统计方法笔记

第 4 空间变系数建模的图正则化路线

空间非平稳性指的是回归关系随地理位置变化，这是空间数据分析的 基本挑战。经典工具是地理加权回归（GWR, Fotheringham, Brunsdon & Charlton 1996 (Fotheringham et al. 1996)），它在每个位置 \(u\) 处做核加权局部回归。GWR 有三个已知缺陷：其一，每个位置的 局部设计矩阵可能病态，系数估计方差偏大；其二，估计对窗宽 \(h\) 高度敏感；其三，所有系数处处变化，即便某些效应实际为全局常数， 也无法识别，缺乏简约性。

与局部加权相对的是全局正则化路线：把 \(n\) 个位置的系数作为一个 整体，用惩罚项同时施加稀疏（哪些系数真正随空间变化）与平滑 （空间相邻的系数应当相近）。该路线的工具包括图拉普拉斯（谱图 论）、组 Lasso（结构化稀疏）、高斯马尔可夫随机场（先验解释）与 ADMM（凸优化）。稀疏-平滑空间变系数分位回归（SS–SVCQR, Hou, Meng, Tian, Pan & Härdle 2026 (Hou, Meng, Tian, Pan, et al. 2026)）把变系数分解为全局 基线加空间偏差，以组 \(L_2\) 惩罚实现稀疏、以归一化图拉普拉斯惩罚 实现平滑，在分位损失下以 ADMM 求解。本章展开该方法所需的数学 准备与推导。

4.1 数学准备

4.1.1 邻接矩阵与三种拉普拉斯

把 \(n\) 个空间位置视为图的顶点，边由邻近关系定义。设 \(A\) 为对称 邻接矩阵（\(A_{i\ell} > 0\) 当且仅当 \(i, \ell\) 相邻）， \(D = \mathrm{diag}(A\mathbf 1)\) 为度矩阵。图上有三种常用拉普拉斯：

名称 定义 谱范围 适用
组合拉普拉斯 \(L = D - A\) \([0, 2d_{\max}]\) 规则网格
对称归一化 \(L_{\mathrm{sym}} = I - D^{-1/2} A D^{-1/2}\) \([0, 2]\) 不规则采样
随机游走 \(L_{\mathrm{rw}} = I - D^{-1} A\) \([0, 2]\) 概率解释

对称归一化拉普拉斯有两个优点：谱界于 \([0, 2]\)，惩罚强度与 \(n\) 无关；度归一化使密集采样区域的惩罚不被放大——空间数据常呈聚簇， 组合拉普拉斯 \(D - A\) 在聚簇处会给出更大的二次型。

谱界 \([0, 2]\) 的证明如下。对任意 \(v\)，

\[ v^\top L_{\mathrm{sym}} v = \frac12 \sum_{i,\ell} A_{i\ell} \left(\frac{v_i}{\sqrt{d_i}} - \frac{v_\ell}{\sqrt{d_\ell}}\right)^2 \ge 0, \]

且由 \(A_{i\ell} \le \sqrt{d_i d_\ell}\)（Cauchy–Schwarz 不等式），

\[ v^\top L_{\mathrm{sym}} v \le \sum_{i,\ell} A_{i\ell}\Bigl(\frac{v_i^2}{d_i} + \frac{v_\ell^2}{d_\ell}\Bigr) = 2 \sum_i v_i^2, \]

即 \(0 \le v^\top L_{\mathrm{sym}} v \le 2\|v\|^2\)。粗糙度二次型 \(\delta_j^\top L_{\mathrm{sym}} \delta_j\) 正是该半范数的展开形式， 它惩罚的是归一化偏差之比 \(\delta_i/\sqrt{d_i} - \delta_\ell/\sqrt{d_\ell}\)， 而非原始偏差——这正是度归一化的体现。

4.1.2 内蕴高斯马尔可夫随机场

\(L_{\mathrm{sym}}\) 半正定且奇异（零空间包含 \(D^{1/2}\mathbf 1_C\)）。 把它作为精度矩阵得到的是内蕴高斯马尔可夫随机场（intrinsic GMRF）：

\[ p(\delta) \propto \exp\Bigl\{-\frac{\lambda_2^2}{2}\, \delta^\top L_{\mathrm{sym}} \delta\Bigr\}, \]

“内蕴”指该密度不可归一化（\(L\) 奇异导致积分发散），只能以条件分布 的形式使用。其条件解释为：对每个顶点 \(i\)，

\[ \delta_i \mid \delta_{-i} \sim N\!\Bigl(\frac{1}{\sqrt{d_i}}\sum_{\ell \in \mathcal{N}(i)} \frac{A_{i\ell}}{\sqrt{d_\ell}} \delta_\ell,\ \frac{1}{\lambda_2^2 d_i}\Bigr), \]

即 \(\delta_i\) 的条件均值是邻居的度加权归一化平均，条件方差与度成 反比——度大的顶点信息更多、先验更紧。把图拉普拉斯正则化理解为 先验后，\(\lambda_2\) 即先验精度。

4.1.3 组惩罚

稀疏惩罚取组 \(L_2\) 范数 \(\lambda_1 w_j \|\delta_j\|_2\)。它与逐元素 \(L_1\) 的差别在于：\(L_1\)（lasso）把 \(\delta_j\) 的个别元素压到零， 对”处处为零 vs 处处非零”的结构选择是错误工具——它会把一个平滑场 挖成稀疏噪声；组 \(L_2\)（group lasso）把整组 \(\delta_j\)（\(n\) 个 位置的向量）作为一个原子，要么整体保留、要么整体为零，恰与 “该系数是否随空间变化”的二值决策对应。

组惩罚的邻近算子为组软阈值：

\[ \mathrm{prox}_{\lambda \|\cdot\|_2}(v) = \begin{cases} 0, & \|v\|_2 \le \lambda,\\ v\,(1 - \lambda/\|v\|_2), & \|v\|_2 > \lambda, \end{cases} \]

与 lasso 的逐元素软阈值同构，只是阈值作用在范数上。自适应权重 \(w_j = (\|\tilde\delta_j\|_2 + a)^{-\gamma}\) 借鉴自适应 Lasso (Zou 2006)：先粗估 \(\tilde\delta_j\)，范数小的组获得更大的 惩罚、更易被剔除——这是 oracle 选择性质的关键。

4.1.4 分位损失的次梯度与近端映射

Check 损失 \(\rho_\tau(u) = u(\tau - \mathbf 1\{u<0\})\) 在 \(u=0\) 处不可微，其次梯度为

\[ \partial \rho_\tau(u) = \tau - \mathbf 1\{u < 0\} - [0,1]\cdot \mathbf 1\{u = 0\}. \]

其近端映射为不对称软阈值：

\[ \mathrm{prox}_{\gamma \rho_\tau}(v) = \begin{cases} v - \gamma\tau, & v > \gamma\tau,\\ 0, & -\gamma(1-\tau) \le v \le \gamma\tau,\\ v + \gamma(1-\tau), & v < -\gamma(1-\tau), \end{cases} \]

推导即最小化 \(\rho_\tau(u) + \frac{1}{2\gamma}(u-v)^2\)，由一阶 条件 \(v - u \in \gamma\,\partial\rho_\tau(u)\) 分三段解出。\(\tau = 1/2\) 时退化为对称软阈值（\(L_1\) 去噪），\(\tau \neq 1/2\) 时阈值区间 不对称——这是分位损失不对称性在算法层的体现。

4.1.5 ADMM

ADMM 把原问题拆成光滑二次部分与可分离的非光滑部分，用对偶变量 耦合。以本章的目标函数为例，三个模块均为闭式更新：

  1. \((\alpha, \beta_G)\) 更新：二次型最小化归结为线性方程组，设计 矩阵 \([Z\ X]\) 固定，可预分解一次（Cholesky），每轮只做回代；
  2. \(s\)（残差）更新：Check 损失的近端映射为不对称软阈值，逐元素 闭式；
  3. \(\delta_j\) 更新：二次型（拉普拉斯平滑）加组惩罚，先解 \((2\lambda_2 L + \rho_s X_{\odot j} X_{\odot j}^\top + \rho_z I)\delta_j = \text{常数}\) 再作用组软阈值；系数矩阵因 \(L\) 稀疏而稀疏，可用共轭梯度或 预分解求解。

ADMM 的收敛保证来自目标函数的凸性与各子问题的精确求解；数值 实验显示几十轮内即可实用收敛。

4.2 详细推导

4.2.1 可识别性约束

分解 \(\beta_j(u) = \beta_{G,j} + \delta_j(u)\) 有一个自由度过剩： 把 \(\beta_{G,j}\) 加上常数 \(c\) 同时把 \(\delta_j\) 减去 \(c\)，得到的 \(\beta_j(\cdot)\) 不变。约束 \(\mathbf 1_C^\top D \delta_j = 0\) （每个连通分量上的度加权中心化）是消除该自由度的一种规范选择。 其几何含义如下：\(L_{\mathrm{sym}}\) 的零空间由 \(D^{1/2}\mathbf 1_C\) 张成，约束 \(D^{1/2}\delta_j \perp D^{1/2}\mathbf 1_C\)（等价于 \(\mathbf 1_C^\top D \delta_j = 0\)）使 \(\delta_j\) 落在零空间的正交 补上。在此约束下，\(\beta_{G,j}\) 恰为 \(\beta_j(\cdot)\) 的度加权 空间平均：

\[ \beta_{G,j} = \frac{\sum_i d_i \beta_j(u_i)}{\sum_i d_i}, \]

偏差 \(\delta_j\) 才是纯粹的空间变化部分。对应的投影算子即减去每个 分量上的加权均值，在每轮迭代之后执行一次。

4.2.2 空间分块交叉验证

\((\lambda_1, \lambda_2)\) 的选取不能使用普通的 \(K\) 折交叉验证：随机 分折会把空间邻近的样本分入不同折，空间相关性使验证集发生泄漏。 空间分块交叉验证把研究区域划分为 \(K\) 个空间块（例如对位置做 \(k\)-means 聚类），每折以整块作为验证。块的数目 \(K\) 建议取 \(5 \sim 10\)，且块的大小应大于图的有效相关长度（约为高斯核的 \(2\sigma\)），否则泄漏依旧。

4.3 实现与计算

  1. kNN 图：\(k\) 太小图不连通（\(L\) 零空间分裂，约束变复杂）， 太大图过密（惩罚失去局部性）。经验取 \(k = 6 \sim 10\)，并检查 图连通性；互 kNN（\(u_\ell \in \mathcal{N}_k(u_i)\) 或 \(u_i \in \mathcal{N}_k(u_\ell)\)）比双向 kNN 更易保证连通性。
  2. 高斯核带宽 \(\sigma\)：邻接权重 \(\exp(-\|u_i - u_\ell\|^2/\sigma^2)\) 中的 \(\sigma\) 可取位置距离的某一分位数（如中位数距离的一半）； 权重对 \(\sigma\) 的敏感度远低于 GWR 窗宽对 \(h\) 的敏感度——因为 \(L\) 只做相对平滑，绝对尺度由 \(\lambda_2\) 吸收。
  3. \(\lambda_2\) 的退化极限：\(\lambda_2 \to \infty\) 强制 \(\delta_j\) 在连通分量上为常数，模型退化为全局回归；\(\lambda_2 \to 0\) 时 \(\delta_j\) 无平滑，每个位置独立。网格搜索时这两个方向都是合法 边界，观察解是否退化可缩小搜索范围。
  4. 度为零的顶点：孤立点 \(d_i = 0\) 使 \(D^{-1/2}\) 无定义；应在 建图后删除孤立点，或强制 \(k \ge 1\)。

4.4 数值例

例 1：kNN 图与归一化拉普拉斯的粗糙度。 验证谱界 \([0, 2]\) 与粗糙度的归一化偏差形式，并比较平滑场与噪声场的粗糙度。

set.seed(2026)
n <- 80
u <- cbind(runif(n), runif(n))
dist_mat <- as.matrix(dist(u))
k <- 8
A <- matrix(0, n, n)
for (i in 1:n) {
  nn <- order(dist_mat[i, ])[2:(k + 1)]
  A[i, nn] <- exp(-dist_mat[i, nn]^2 / (2 * 0.15^2))
}
A <- (A + t(A)) / 2; A[A > 0] <- 1
d <- rowSums(A)
L <- diag(n) - diag(1 / sqrt(d)) %*% A %*% diag(1 / sqrt(d))
ev <- eigen(L, symmetric = TRUE)$values
cat("eigenvalue range of Lsym:", round(min(ev), 3), "to", round(max(ev), 3), "\n")
## eigenvalue range of Lsym: 0 to 1.362
delta <- sin(2 * pi * u[, 1])            # 平滑场
noise <- rnorm(n)                        # 粗糙场
cat("roughness(smooth)/||d||2:", round(sum(delta * (L %*% delta)) / sum(delta^2), 3), "\n")
## roughness(smooth)/||d||2: 0.223
cat("roughness(noise)/||d||2:", round(sum(noise * (L %*% noise)) / sum(noise^2), 3), "\n")
## roughness(noise)/||d||2: 0.978

平滑场的粗糙度远小于噪声场：在相同的 \(\lambda_2\) 下，平滑的 \(\delta\) 付出的正则化代价低、粗糙的 \(\delta\) 代价高，这正是 “\(L\) 惩罚平滑偏差”的机制。

例 2：组软阈值的整组收缩。 比较组惩罚对零组与非零组的差别 处理。

prox_group <- function(v, lam) {
  nrm <- sqrt(sum(v^2))
  if (nrm <= lam) rep(0, length(v)) else v * (1 - lam / nrm)
}
set.seed(2026)
v_zero <- rnorm(10, 0, 0.3)     # 应收缩为零的组
v_real <- rnorm(10, 3, 0.5)     # 应保留的组
cat("||prox(v_zero, 2)||2 =", round(sqrt(sum(prox_group(v_zero, 2)^2)), 3), "\n")
## ||prox(v_zero, 2)||2 = 0
cat("||prox(v_real, 2)||2 =", round(sqrt(sum(prox_group(v_real, 2)^2)), 3),
    " (before:", round(sqrt(sum(v_real^2)), 3), ")\n")
## ||prox(v_real, 2)||2 = 7.299  (before: 9.299 )
