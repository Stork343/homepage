第 4 空间变系数建模的图正则化路线

对应论文：Hou Jian, Meng Tan, Tian Maozai, Jianxin Pan, Wolfgang Karl Härdle. Sparse–smooth spatially varying coefficient quantile regression. Spatial Statistics, 2026, 74, 100983 (Hou, Meng, Tian, Pan, et al. 2026)。本章是论文的 补充材料：补齐图拉普拉斯、内蕴 GMRF、组惩罚与 ADMM 这些论文直接 使用但未展开的工具。

4.1 背景与动机

问题起源。 空间非平稳性指回归关系随地理位置变化。经典工具是 GWR (Fotheringham et al. 1996)：在每个位置 \(u\) 处做核加权 局部回归。GWR 有三个已知缺陷：

  1. 多重共线性：每个位置的局部设计矩阵可能病态，系数估计 方差大；
  2. 带宽敏感：窗宽 \(h\) 的小变动导致估计大变动；
  3. 缺乏简约性：所有系数处处变化——即使某效应实际是全局常数， GWR 也给出 \(n\) 个不同的局部估计，解释困难。

正则化路线的谱系。 与”局部加权”相对的是”全局正则化”：把 \(n\) 个位置的系数作为整体，用惩罚项同时施加稀疏（哪些系数 真正随空间变化）与平滑（空间上相邻的系数应相近）。这一路线 的工具箱包括：图拉普拉斯（谱图论）、组 Lasso（结构化稀疏）、 高斯马尔可夫随机场（贝叶斯解释）、ADMM（凸优化）。论文的 SS–SVCQR 是这些工具在”空间变系数分位回归”上的组合。本章逐一 补齐工具本身。

4.2 论文工作概览

论文把每个变系数 \(\beta_j(u)\) 分解为全局基线 \(\beta_{G,j}\) 与空间 偏差 \(\delta_j(u)\)；用组 \(L_2\) 惩罚让不必要的 \(\delta_j\) 整组收缩 为零（稀疏），用归一化图拉普拉斯惩罚让保留的 \(\delta_j\) 空间平滑； 在分位损失下用 ADMM 求解；理论上证明全局估计量的 \(\sqrt{n}\) 正态性与”全局 vs 局部”结构的选择一致性。

4.3 数学工具详解

4.3.1 图、邻接矩阵与三种拉普拉斯

把 \(n\) 个空间位置看成图的顶点，边由邻近关系定义。设 \(A\) 为对称 邻接矩阵（\(A_{i\ell} > 0\) 当且仅当 \(i, \ell\) 相邻）， \(D = \mathrm{diag}(A\mathbf 1)\) 为度矩阵。图上有三种常用拉普拉斯：

名称 定义 谱范围 适用
组合拉普拉斯 \(L = D - A\) \([0, 2d_{\max}]\) 规则网格
对称归一化 \(L_{\mathrm{sym}} = I - D^{-1/2} A D^{-1/2}\) \([0, 2]\) 不规则采样
随机游走 \(L_{\mathrm{rw}} = I - D^{-1} A\) \([0, 2]\) 概率解释

论文用 \(L_{\mathrm{sym}}\)，理由有二：（i）谱界于 \([0,2]\)，惩罚强度 与 \(n\) 无关；（ii）度归一化使密集采样区域不会被过度惩罚——空间 数据常聚簇，\(D - A\) 在聚簇处会给出更大的二次型。

谱界 \([0, 2]\) 的证明（补充）。 对任意 \(v\)：

\[ v^\top L_{\mathrm{sym}} v = \frac12 \sum_{i,\ell} A_{i\ell} \left(\frac{v_i}{\sqrt{d_i}} - \frac{v_\ell}{\sqrt{d_\ell}}\right)^2 \ge 0, \]

且由 \(A_{i\ell} \le \sqrt{d_i d_\ell}\)（Cauchy–Schwarz），

\[ v^\top L_{\mathrm{sym}} v \le \sum_{i,\ell} A_{i\ell}\Bigl(\frac{v_i^2}{d_i} + \frac{v_\ell^2}{d_\ell}\Bigr) = 2 \sum_i v_i^2, \]

即 \(0 \le v^\top L_{\mathrm{sym}} v \le 2\|v\|^2\)。论文式 (6) 的 粗糙度二次型就是这个半范数的展开形式——它惩罚的是归一化偏差 之比 \(\delta_i/\sqrt{d_i} - \delta_\ell/\sqrt{d_\ell}\)，而非原始 偏差，这正是度归一化的体现。

4.3.2 内蕴高斯马尔可夫随机场

\(L_{\mathrm{sym}}\) 半正定且奇异（零空间含 \(D^{1/2}\mathbf 1_C\)）， 把它当精度矩阵得到的是内蕴 GMRF（intrinsic GMRF）：

\[ p(\delta) \propto \exp\Bigl\{-\frac{\lambda_2^2}{2}\, \delta^\top L_{\mathrm{sym}} \delta\Bigr\}, \]

“内蕴”指这个密度是不可归一化的（\(L\) 奇异 → 积分发散）， 只能作为条件分布使用。其条件解释很直观：对每个顶点 \(i\)，

\[ \delta_i \mid \delta_{-i} \sim N\!\Bigl(\frac{1}{\sqrt{d_i}}\sum_{\ell \in \mathcal{N}(i)} \frac{A_{i\ell}}{\sqrt{d_\ell}} \delta_\ell,\ \frac{1}{\lambda_2^2 d_i}\Bigr), \]

即 \(\delta_i\) 的条件均值是邻居的度加权归一化平均，条件方差与 度成反比（度大的顶点信息多、先验更紧）。把正则化理解为”先验”后， \(\lambda_2\) 就是先验精度——这是论文”贝叶斯解释”的全部内容。

4.3.3 组惩罚：为什么是 \(\|\delta_j\|_2\) 而不是 \(\|\delta_j\|_1\)

论文的稀疏惩罚是组 \(L_2\) 范数 \(\lambda_1 w_j \|\delta_j\|_2\)。与 逐元素 \(L_1\) 的差别：

  • \(L_1\)（lasso） 把 \(\delta_j\) 的个别元素压到零——对 “空间上处处为零 vs 处处非零”的结构选择是错误工具（会把一个 平滑场挖成稀疏噪声）；
  • 组 \(L_2\)（group lasso） 把整组 \(\delta_j\)（\(n\) 个位置 的向量）作为一个原子：要么整体保留、要么整体为零。这正是 “该系数是否随空间变化”的二值决策。

组惩罚的邻近算子（proximal map）是组软阈值：

\[ \mathrm{prox}_{\lambda \|\cdot\|_2}(v) = \begin{cases} 0, & \|v\|_2 \le \lambda,\\ v\,(1 - \lambda/\|v\|_2), & \|v\|_2 > \lambda, \end{cases} \]

与 lasso 的逐元素软阈值同构，只是阈值作用在范数上。自适应权重 \(w_j = (\|\tilde\delta_j\|_2 + a)^{-\gamma}\) 模仿自适应 Lasso (Zou 2006)：先粗估 \(\tilde\delta_j\)，范数小的组获得大 惩罚、更容易被剔除——保证 oracle 性质的关键。

4.3.4 分位损失的次梯度与近端映射

check loss \(\rho_\tau(u) = u(\tau - \mathbf 1\{u<0\})\) 在 \(u=0\) 处不可微，次梯度为

\[ \partial \rho_\tau(u) = \tau - \mathbf 1\{u < 0\} - [0,1]\cdot \mathbf 1\{u = 0\}. \]

其近端映射（论文式 (13)）是不对称软阈值：

\[ \mathrm{prox}_{\gamma \rho_\tau}(v) = \begin{cases} v - \gamma\tau, & v > \gamma\tau,\\ 0, & -\gamma(1-\tau) \le v \le \gamma\tau,\\ v + \gamma(1-\tau), & v < -\gamma(1-\tau), \end{cases} \]

推导：最小化 \(\rho_\tau(u) + \frac{1}{2\gamma}(u-v)^2\)，一阶条件 \(v - u \in \gamma\,\partial\rho_\tau(u)\)，分三段解出。\(\tau = 1/2\) 时退化为对称软阈值（L1 去噪），\(\tau \neq 1/2\) 时阈值区间不对称 ——这是分位损失”不对称”在算法层的体现。

4.3.5 ADMM 的套路：为什么每步都是闭式

ADMM 把原问题拆成”光滑二次部分”与”可分离非光滑部分”，用对偶 变量耦合。论文问题（式 (12)）的三个模块：

  1. \((\alpha, \beta_G)\) 更新：二次型最小化 → 线性方程组，设计 矩阵 \([Z\ X]\) 固定，可预分解一次（Cholesky），每轮只做回代；
  2. \(s\) 更新（残差）：check loss 的近端映射 → 不对称软阈值， 逐元素闭式；
  3. \(\delta_j\) 更新：二次型（拉普拉斯平滑）+ 组惩罚 → 解 \((2\lambda_2 L + \rho_s X_{\odot j} X_{\odot j}^\top + \rho_z I)\delta_j = \text{常数}\) 后接组软阈值；系数矩阵稀疏（\(L\) 稀疏），用共轭梯度或预分解。

ADMM 的收敛保证来自目标函数凸性 + 各子问题精确求解。 论文的数值部分显示几十轮内实用收敛。

4.4 论文未展示的详细推导

4.4.1 可识别性约束从哪来

分解 \(\beta_j(u) = \beta_{G,j} + \delta_j(u)\) 有一个自由度过剩： 把 \(\beta_{G,j}\) 加上常数 \(c\)、\(\delta_j\) 减去 \(c\) 得到同一个 \(\beta_j(\cdot)\)。论文的约束 \(\mathbf 1_C^\top D \delta_j = 0\) （每个连通分量上度加权中心化）是消除该自由度的一种规范选择。 它的几何含义：\(L_{\mathrm{sym}}\) 的零空间由 \(D^{1/2}\mathbf 1_C\) 张成，约束 \(D^{1/2}\delta_j \perp D^{1/2}\mathbf 1_C\)（等价于 \(\mathbf 1_C^\top D \delta_j = 0\)）让 \(\delta_j\) 落在零空间的正交 补上。在此约束下，\(\beta_{G,j}\) 恰为 \(\beta_j(\cdot)\) 的度加权 空间平均：

\[ \beta_{G,j} = \frac{\sum_i d_i \beta_j(u_i)}{\sum_i d_i}, \]

偏差 \(\delta_j\) 才是纯粹的”空间变化”部分。约束的投影算子（论文 式 (11)）就是减去每分量上的加权均值，每轮迭代后执行一次。

4.4.2 空间分块交叉验证

\((\lambda_1, \lambda_2)\) 的选取不能用普通 \(K\)-折 CV：随机分折会把 空间邻近的样本分到不同折，空间相关性使验证集”泄漏”。空间分块 CV 把研究区域划分成 \(K\) 个空间块（如 \(k\)-means 聚类位置），每折用 整块做验证。论文补充材料未展示的细节：块的数目 \(K\) 建议取 \(5 \sim 10\)，块大小应大于图的有效相关长度（\(\approx\) 高斯核的 \(2\sigma\)），否则泄漏依旧。

4.5 实现细节与数值注意

  1. kNN 图：\(k\) 太小图不连通（\(L\) 零空间分裂，约束复杂）， 太大图过密（惩罚失去局部性）。经验取 \(k = 6 \sim 10\)，并检查 图连通性；论文的”互 kNN”（\(u_\ell \in \mathcal{N}_k(u_i)\) 或 \(u_i \in \mathcal{N}_k(u_\ell)\)）比”双向 kNN”更容易保证连通。
  2. 高斯核带宽 \(\sigma\)：邻接权重 \(\exp(-\|u_i - u_\ell\|^2/\sigma^2)\) 的 \(\sigma\) 可取位置距离的某个分位数（如中位数距离的 \(1/2\)）； 权重对 \(\sigma\) 的敏感度远低于 GWR 的窗宽对 \(h\) 的敏感度 （因为 \(L\) 只做相对平滑，绝对尺度由 \(\lambda_2\) 吸收）。
  3. \(\lambda_2\) 很大时的退化：\(\lambda_2 \to \infty\) 强制 \(\delta_j\) 在连通分量上为常数 → 模型退化为全局回归；\(\lambda_2 \to 0\) 时 \(\delta_j\) 无平滑 → 每个位置独立。网格搜索 \(\lambda_2\) 时这两个方向都是合法边界，注意观察解是否退化以缩小搜索范围。
  4. 度为零的顶点：孤立点 \(d_i = 0\) 使 \(D^{-1/2}\) 无定义； 应在建图后删除孤立点或强制 \(k \ge 1\)。

4.6 数值演示

演示 1：kNN 图与归一化拉普拉斯的粗糙度。 验证谱界 \([0,2]\) 与粗糙度的”归一化偏差”形式。

set.seed(2026)
n <- 80
u <- cbind(runif(n), runif(n))
dist_mat <- as.matrix(dist(u))
k <- 8
A <- matrix(0, n, n)
for (i in 1:n) {
  nn <- order(dist_mat[i, ])[2:(k + 1)]
  A[i, nn] <- exp(-dist_mat[i, nn]^2 / (2 * 0.15^2))
}
A <- (A + t(A)) / 2; A[A > 0] <- 1
d <- rowSums(A)
L <- diag(n) - diag(1 / sqrt(d)) %*% A %*% diag(1 / sqrt(d))
ev <- eigen(L, symmetric = TRUE)$values
cat("eigenvalue range of Lsym:", round(min(ev), 3), "to", round(max(ev), 3), "\n")
## eigenvalue range of Lsym: 0 to 1.362
delta <- sin(2 * pi * u[, 1])            # 平滑场
noise <- rnorm(n)                        # 粗糙场
cat("roughness(smooth)/||d||2:", round(sum(delta * (L %*% delta)) / sum(delta^2), 3), "\n")
## roughness(smooth)/||d||2: 0.223
cat("roughness(noise)/||d||2:", round(sum(noise * (L %*% noise)) / sum(noise^2), 3), "\n")
## roughness(noise)/||d||2: 0.978

平滑场的粗糙度远小于噪声场——这正是”\(L\) 惩罚平滑偏差”的机制： 同一 \(\lambda_2\) 下，平滑 \(\delta\) 付出的代价低、粗糙 \(\delta\) 付出的代价高。

演示 2：组软阈值的整组收缩。 展示组惩罚对”真为零的组”与 “真非零的组”的差别处理。

prox_group <- function(v, lam) {
  nrm <- sqrt(sum(v^2))
  if (nrm <= lam) rep(0, length(v)) else v * (1 - lam / nrm)
}
set.seed(2026)
v_zero <- rnorm(10, 0, 0.3)     # 应收缩为零的组
v_real <- rnorm(10, 3, 0.5)     # 应保留的组
cat("||prox(v_zero, 2)||2 =", round(sqrt(sum(prox_group(v_zero, 2)^2)), 3), "\n")
## ||prox(v_zero, 2)||2 = 0
cat("||prox(v_real, 2)||2 =", round(sqrt(sum(prox_group(v_real, 2)^2)), 3),
    " (before:", round(sqrt(sum(v_real^2)), 3), ")\n")
## ||prox(v_real, 2)||2 = 7.299  (before: 9.299 )
