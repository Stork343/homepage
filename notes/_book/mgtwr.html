统计方法笔记

第 6 时空回归的混合设定与变量选择

地理加权回归（GWR, Fotheringham, Brunsdon & Charlton 1996 (Fotheringham et al. 1996)）让回归系数随空间位置变化； GTWR (Huang et al. 2010) 在此基础上把时间维度纳入邻近度量； 混合 GWR（MGWR）允许一部分系数保持全局常数、另一部分随空间变化。 混合时空地理加权回归（MGTWR, 侯健 & 田茂再 2021 (侯健 and 田茂再 2021)） 是这一谱系的自然端点：固定系数部分刻画全局平稳特征，时空变系数 部分刻画局部非平稳特征，且 OLR、GWR、MGWR、GTWR 都是它的退化 情形。

MGTWR 的参数估计采用两步法：先估计时空变系数部分，再从残差中 估计固定系数。这隐含一个强假设——固定系数指标不含任何时空效应。 实际问题中，被当作固定的指标可能事实上随空间或时间漂移（例如某 经济变量在不同城市的作用不同）；此时两步法会把这种漂移错误地吸收 进固定系数估计。基于变量选择的估计方法通过检验固定指标的时空 平稳性，剔除携带交互效应的指标。本章给出核方法工具与偏差分析。

6.1 数学准备

6.1.1 核函数

时空加权估计依赖核权重 \(w_{ij} = K_h(d_{ij})\)。两种常用核为：

核 公式 支撑 特点
Gauss \(K(d) = \exp(-d^2/h^2)\) 全空间 处处正权重，无截断
Bisquare \(K(d) = (1 - (d/h)^2)^2 \cdot \mathbf 1\{d < h\}\) 紧支撑 权重在 \(h\) 处平滑截断为 0

两者都在 \(d = 0\) 处取权重 1 并随距离单调下降。Gauss 核的权重永不 为零（需计入所有样本），Bisquare 核只使用邻域内的样本（稀疏、更 快）。窗宽 \(h\) 控制偏差与方差的权衡：\(h\) 越小局部性越强，偏差小 而方差大；\(h\) 越大越接近全局回归，偏差大方差小。第 7 章的异窗宽设定正是针对”不同区域的最优 \(h\) 不同”这一事实。

6.1.2 时空距离与权重矩阵

GTWR 的邻近度量是时空距离的加权合成：

\[ d_{ij}^{ST} = \sqrt{\lambda\bigl[(u_i - u_j)^2 + (v_i - v_j)^2\bigr] + \mu (t_i - t_j)^2}, \]

其中 \((\lambda, \mu)\) 为尺度参数，把空间距离与时间距离换算到同一 尺度（类似马氏距离）。一个实现中的常见陷阱是 \((\lambda, \mu)\) 与 \(h\) 之间不可识别：实际上只有比值 \(\lambda/h^2\) 是有效量。因此通常 先对坐标与时间做标准化，固定 \(\lambda = \mu = 1\)，只对 \(h\) 搜索。

6.1.3 加权最小二乘与帽子矩阵

固定系数 \(a\) 的估计采用时空加权最小二乘：

\[ \hat a(r) = \bigl(A^{(f)\top} W A^{(f)}\bigr)^{-1} A^{(f)\top} W \tilde Y, \]

其中 \(W = \mathrm{diag}(w_1(h), \dots, w_n(h))\)。这是广义最小二乘 的特例（\(W\) 已知对角）：展开 \(\|W^{1/2}(\tilde Y - A^{(f)}a)\|^2\) 并对 \(a\) 求导置零即得闭式解。帽子矩阵 \(S = A^{(c)}(A^{(c)\top} W A^{(c)})^{-1} A^{(c)\top} W\) 满足 \(\hat{\delta} = S \tilde Y\)，其迹 \(\mathrm{tr}(S)\) 是模型的有效参数 个数（有效自由度），用于 AICc 型准则的窗宽选择。

6.1.4 变量选择的动机

变量选择针对固定系数指标。直觉：若第 \(k\) 个”固定”指标实际携带 时空效应（即真实模型应为变系数），两步法在迭代中会用变系数部分的 残差污染 \(a_k\) 的估计。将该指标从固定部分剔除后，其效应由变系数 部分（时空核加权）吸收，\(a\) 的估计不再被污染——以参数个数的小幅 增加换取偏差的大幅下降。

6.2 详细推导

6.2.1 两步估计的偏差

设真实模型为 \(Y = X^{(f)} a_0 + X^{(c)} b_0(u,t) + \varepsilon\)， 但实现时把 \(X^{(c)}\) 的一部分（记作 \(X^{(i)}\)）误当作固定指标。 令 \(a_0 = (a_{0,1}^\top, a_{0,2}^\top)^\top\)，且 \(X^{(i)}\) 对应的 真实系数其实是时空函数 \(b_0^{(i)}(u,t) = a_{0,2} + \delta_0^{(i)}(u,t)\)，即常数加时空偏差。两步法的第一步用局部估计 \(\hat b\) 时，\(X^{(i)}\) 不在变系数设计矩阵中，其效应 \(\delta_0^{(i)}\) 残留在 \(\tilde Y\) 中；第二步的固定系数估计为

\[ \hat a = a_0 + \bigl(X^{(f)\top} W X^{(f)}\bigr)^{-1} X^{(f)\top} W \cdot X^{(i)} \delta_0^{(i)} + \text{噪声项}. \]

偏差项 \(\bigl(X^{(f)\top} W X^{(f)}\bigr)^{-1} X^{(f)\top} W X^{(i)} \delta_0^{(i)}\) 是把 \(X^{(i)}\) 的时空偏差回归到固定指标空间的结果。 只要 \(\delta_0^{(i)}\) 与 \(X^{(f)}\) 相关，\(\hat a\) 就有偏。变量选择 通过检验 \(\delta_0^{(i)}\) 是否显著非零来剔除这类指标。

6.2.2 时空平稳性检验

检验固定指标 \(k\) 的时空平稳性的思路是：把 \(X^{(i)}\) 临时放入变系数 部分，估计 \(\hat b_k(u_i, t_i)\) 并检验其空间变异 \(\mathrm{Var}_i(\hat b_k(u_i, t_i))\) 是否显著大于纯噪声水平；或者用 等价的 F 型检验比较”含该固定指标”与”该指标变系数化”两个模型的 拟合。后者因近似分布已知而更常用。

6.3 实现与计算

  1. 两步迭代的收敛：两步法通常迭代 2–3 轮即稳定；实现时以固定 系数估计的变化小于阈值（如 \(10^{-4}\)）为停止准则，并限制最大 迭代次数（如 20）防止振荡。
  2. \(W\) 的病态：样本点过密时 \(A^{(f)\top} W A^{(f)}\) 可能接近 奇异，加岭修正 \(+ \kappa I\)（\(\kappa\) 取 \(10^{-6}\) 量级）是常用 做法。
  3. 窗宽搜索：对 \(h\) 做网格搜索并结合交叉验证；不同区域应使用 各自区域的窗宽（异窗宽思想见第 7 章），全样本统一 窗宽会掩盖区域差异。
  4. 坐标标准化：经纬度与时间的量纲差异巨大，务必先各自减去均值 除以标准差，否则 \(d^{ST}\) 会被大尺度变量主导。

6.4 数值例

例：两步估计与变量选择的对比。 构造携带时空效应的”伪固定指标”， 比较全模型与剔除后的固定系数估计误差。

set.seed(2026)
n <- 300
u <- runif(n); v <- runif(n); tt <- runif(n)
x1 <- u + rnorm(n, sd = 0.2)     # 与空间坐标相关：遗漏效应将污染其系数
x2 <- rnorm(n)
x3 <- 0.7 * x1 + 0.7 * rnorm(n)  # 与 x1 相关
a_true <- c(1, -0.5)
b_true <- 2 + 5 * u              # x3 的真实效应随空间变化（伪固定指标）
y <- a_true[1] * x1 + a_true[2] * x2 + b_true * x3 + rnorm(n, sd = 0.3)

st_dist <- function(i, j) sqrt((u[i] - u[j])^2 + (v[i] - v[j])^2 + (tt[i] - tt[j])^2)
h <- 0.4
W <- matrix(0, n, n)
for (j in 1:n) W[, j] <- exp(-(sapply(1:n, function(i) st_dist(i, j)))^2 / h^2)

# 错误设定：x3 被当作固定指标，直接做全局回归
Xf <- cbind(x1, x2, x3)
a_full <- solve(t(Xf) %*% Xf, t(Xf) %*% y)

# 变量选择后：x3 进入变系数部分（两步法第 1 步以真值代入，隔离偏差
# 机制；实际估计中固定系数由迭代提供）
b_hat <- sapply(1:n, function(j) {
  w <- W[, j]
  sum(w * x3 * (y - a_true[1] * x1 - a_true[2] * x2)) / sum(w * x3^2)
})
yt <- y - b_hat * x3
Xf2 <- cbind(x1, x2)
a_sel <- solve(t(Xf2) %*% Xf2, t(Xf2) %*% yt)
cat("full model a:", round(a_full[1:2], 3),
    " RMSE:", round(sqrt(mean((a_full[1:2] - a_true)^2)), 3), "\n")
## full model a: 1.879 -0.575  RMSE: 0.624
cat("after selection a:", round(a_sel, 3),
    " RMSE:", round(sqrt(mean((a_sel - a_true)^2)), 3), "\n")
## after selection a: 1.231 -0.515  RMSE: 0.164

图 6.1: 固定系数估计误差：全模型（含伪固定指标）与变量选择后

全模型把 \(x_3\) 的时空效应错误地压入固定系数：\(a_1\) 的估计为 \(1.879\)（真值 \(1\)），固定系数 RMSE 为 \(0.624\)。变量选择后 \(x_3\) 的 效应由变系数部分吸收，\(a_1\) 的估计为 \(1.231\)，RMSE 降至 \(0.164\) （约为全模型的四分之一）。残余偏差来自局部核光滑的有限样本方差 与边界效应——变系数部分不能完全剥离 \(b_{\mathrm{true}}(u)\) 的高频 变化，这正是偏差公式中噪声项与平滑误差的体现。

6.5 注记

  • GWR 的核、带宽与推断的标准参考为 Fotheringham, Brunsdon & Charlton (2002), Geographically Weighted Regression (Fotheringham et al. 1996)。
  • GTWR 的原始论文含时空距离的构造与房价实证，见 Huang, Wu & Barry (2010) (Huang et al. 2010)。
  • 混合 GWR（MGWR）及”哪些系数固定”的检验见 Brunsdon, Fotheringham & Charlton (1999)。
  • 与第 7 章的关联：变量选择回答”哪些指标固定”，异窗宽 回答”固定指标的平滑尺度是否随区域变化”，是同一区域差异问题的 两个层次。
