统计方法笔记

第 7 局部回归的窗宽设定：从同窗宽到异窗宽

商品住宅价格的空间建模中，回归系数（如面积、区位、朝向的影响） 随位置与时间变化。GTWR (Huang et al. 2010) 在 GWR (Fotheringham et al. 1996) 的基础上加入时间维度，是房价 研究的常用工具。但 GTWR 隐含一个假设：所有样本、所有因素共用同 一个窗宽 \(h\)。若城市不同区域的空间异质性强度不同（老城区效应变化 平缓、新开发区效应变化剧烈），单一 \(h\) 必然在某一个区域过拟合、 在另一个区域欠拟合。

窗宽是核回归的平滑参数：\(h\) 小则局部偏差小、方差大，\(h\) 大则 相反。最优 \(h\) 取决于未知的二阶结构（效应曲率）与噪声水平，而 两者都可能随区域变化。异窗宽 GTWR（侯健, 王芝皓, 田茂再 & 窦燕 2022 (侯健 et al. 2022)）把研究区域划分为 \(m\) 个子区域，每个子区域 \(k\) 使用自己的窗宽 \(h_k\)，在各区域内做加权最小二乘；区域划分采用 标准差椭圆分类算法。本章给出窗宽问题的偏差-方差分析、标准差 椭圆的计算与区域划分的算法细节。

7.1 数学准备

7.1.1 局部加权最小二乘的偏差-方差分解

GTWR 在每个位置 \(i\) 处的系数估计为加权最小二乘 \(\hat\beta(u_i) = (X^\top W_i X)^{-1} X^\top W_i y\)。设真实模型为 \(y = X\beta(u) + \varepsilon\)，\(\mathrm{Var}(\varepsilon) = \sigma^2 I\)， 条件偏差与方差为

\[ \mathrm{Bias}\bigl[\hat\beta(u_i)\bigr] \approx \frac{h^2}{2}\,\beta''(u_i) \cdot c_1 + o(h^2), \qquad \mathrm{Var}\bigl[\hat\beta(u_i)\bigr] \approx \frac{\sigma^2\, c_2}{n h^2\, f_u(u_i)}, \]

其中 \(c_1, c_2\) 为核常数，\(f_u\) 为位置密度。由此得到两条规律：

  1. 偏差正比于 \(h^2 \cdot \beta''\)：效应曲率 \(\beta''\) 大的区域（变化 剧烈）需要小 \(h\) 控制偏差；
  2. 方差正比于 \(1/(h^2 \cdot f_u)\)：采样稀疏的区域（\(f_u\) 小）需要 大 \(h\) 控制方差。

同一个 \(h\) 无法同时满足两个区域——这就是异窗宽的数学依据。总均方 误差 \(\mathrm{MSE} = \mathrm{Bias}^2 + \mathrm{Var}\) 对 \(h\) 的权衡 在每处都不同，最优窗宽 \(h^*(u_i)\) 是位置的函数。

7.1.2 标准差椭圆

标准差椭圆（standard deviational ellipse）是描述点集空间分布的 经典工具。给定 \(n\) 个位置 \((u_i, v_i)\)，计算分三步：

  1. 均值中心 \(\bar u = \frac1n\sum u_i\)，\(\bar v = \frac1n\sum v_i\)；
  2. 方向角 \(\theta\) 使坐标旋转后 \(u'v'\) 协方差为零：

\[ \tan 2\theta = \frac{2\sum_i (u_i - \bar u)(v_i - \bar v)} {\sum_i (u_i - \bar u)^2 - \sum_i (v_i - \bar v)^2}; \]

  1. 长短轴标准差在旋转坐标系下计算： \(\sigma_{u'} = \sqrt{\frac{2}{n}\sum_i (u'_i - \bar u')^2}\)， \(\sigma_{v'} = \sqrt{\frac{2}{n}\sum_i (v'_i - \bar v')^2}\) （系数取 2 使椭圆覆盖约 98% 的点，取 1 则约 68%）。

椭圆三个量各有含义：扁率 \(1 - \sigma_{v'}/\sigma_{u'}\) 描述方向的 各向异性（0 为圆，大于 0 为拉长），方向角描述主导方向，面积 \(\pi \sigma_{u'} \sigma_{v'}\) 描述离散程度。分类算法依据这些量： 若两个子区域的标准差椭圆在形态与朝向上差异显著，则说明其空间影响 结构不同，应使用不同的窗宽。

之所以用椭圆而非简单的经纬度网格，是因为网格边界与真实的空间影响 结构无关——斜向延伸的城市走廊会被网格切成碎片。标准差椭圆是数据 驱动的形状，捕捉点集的真实各向异性，分类依据的是空间影响结构的 相似性而非地理位置的邻近性。

7.1.3 异窗宽估计

异窗宽模型把样本划分为 \(m\) 个子区域，权重矩阵 \(W_D = \mathrm{diag}(W_1, \dots, W_m)\)，其中 \(W_k\) 用窗宽 \(h_k\) 构造。第 \(k\) 个区域的系数估计为

\[ \hat\beta_{Dk} = \arg\min_\beta \bigl\| \sqrt{W_k}\,(Y_k - X_k \beta)\bigr\|_2^2 = \bigl(X_k^\top W_k X_k\bigr)^{-1} X_k^\top W_k Y_k, \]

即在子区域 \(k\) 内做一次带权重的普通最小二乘（推导与第 6 章的加权最小二乘相同：展开平方、求导置零）。各区域 的估计互不影响（\(W_D\) 块对角），因此异窗宽模型的计算复杂度与同 窗宽相当——只是把一次 \(n \times n\) 加权拟合换成 \(m\) 次较小的加权 拟合。

7.1.4 有效自由度

同窗宽 GTWR 的有效参数个数为 \(\mathrm{tr}(S)\)（\(S\) 为帽子矩阵， 见第 6 章）。异窗宽的帽子矩阵为 \(S_D = \mathrm{diag}(S_1, \dots, S_m)\)，有效自由度 \(\mathrm{tr}(S_D) = \sum_k \mathrm{tr}(S_k)\)，即各区域自由度的加和。 因此异窗宽模型的自由度自动反映各区域的实际复杂度，AICc 型准则 可以公平地比较同窗宽与异窗宽。

7.1.5 标准差椭圆分类算法

算法步骤为：

  1. 对每个回归指标 \(j\)，计算其系数空间分布（各位置估计 \(\hat\beta_j(u_i)\) 的加权位置）的标准差椭圆参数；
  2. 以椭圆的面积、扁率、方向角为特征，对指标做聚类（层次聚类或 \(k\)-means），得到指标分组；
  3. 同一组的指标共享区域划分与窗宽结构，不同组独立确定窗宽；
  4. 对每组做交叉验证选择 \(h_k\)；若某组的 \(h_k\) 与全局最优 \(h\) 差异小于阈值，则合并该组，以避免过拟合。

7.2 实现与计算

  1. 区域数 \(m\) 的选择：\(m\) 太大则每区域样本过少（方差失控）， \(m\) 太小退化为同窗宽。经验上 \(m = 2 \sim 4\) 在房价数据上表现 稳定，可用 BIC 型准则或肘部法则辅助选择。
  2. 椭圆参数的稳健性：均值中心与标准差对离群位置敏感；若数据 含离群楼盘，可用中位数中心与 MAD 尺度替代。
  3. \(h_k\) 的搜索范围：每个区域的 \(h_k\) 用该区域的距离分位数 确定网格（如在 \(10\%\) 到 \(90\%\) 分位数之间取 10 个候选），避免 跨区域比较时量纲不一致。
  4. 同窗宽与异窗宽的比较：应在同一准则下进行（AICc 或交叉验证 MSE）。异窗宽通常在拟合优度上占优，但解释上更复杂——报告时应 同时给出两套结果。

7.3 数值例

例：单一窗宽无法同时适应两个异质性不同的区域。 构造两个子 区域（效应平缓 vs 剧烈），比较小窗宽、大窗宽与”各自最优”（异窗宽） 的拟合误差。

set.seed(2026)
nA <- 100; nB <- 100
uA <- runif(nA); uB <- runif(nB)
xA <- rnorm(nA); xB <- rnorm(nB)
bA <- 1 + 0.5 * uA; bB <- 1 + 4 * uB
yA <- bA * xA + rnorm(nA, sd = 0.3); yB <- bB * xB + rnorm(nB, sd = 0.3)

gauss_w <- function(d, h) exp(-(d / h)^2)
local_fit <- function(u, x, y, u0, h) {
  w <- gauss_w(abs(u - u0), h)
  sum(w * x * y) / sum(w * x^2)
}
grid <- seq(0, 1, length.out = 40)
rmse_h <- function(h) {
  predA <- sapply(grid, function(u0) local_fit(uA, xA, yA, u0, h))
  predB <- sapply(grid, function(u0) local_fit(uB, xB, yB, u0, h))
  c(A = sqrt(mean((predA - (1 + 0.5 * grid))^2)),
    B = sqrt(mean((predB - (1 + 4 * grid))^2)))
}
h_small <- rmse_h(0.08); h_large <- rmse_h(0.35)
h_bestA <- rmse_h(0.35)["A"]; h_bestB <- rmse_h(0.08)["B"]   # 各自最优
tab <- rbind(small_h = h_small, large_h = h_large,
             best_each = c(h_bestA, h_bestB))
colnames(tab) <- c("region A (smooth)", "region B (steep)")
round(tab, 3)
##           region A (smooth) region B (steep)
## small_h               0.080            0.127
## large_h               0.074            0.422
## best_each             0.074            0.127

图 7.1: 三种窗宽策略在两个区域上的拟合 RMSE

结果解读：小窗宽在平缓区域 A 过拟合（RMSE 高于大窗宽），大窗宽在 剧烈区域 B 严重欠拟合；“各自最优”（异窗宽）在每个区域都达到最低 RMSE。这正是异窗宽设定优于同窗宽的机制，也是第 6 章 区域差异主题的数值落点。
